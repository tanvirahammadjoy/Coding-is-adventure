# CompTIA A+ Core 2 (220-1202) Masterclass

A complete study course built around the four official 220-1202 exam domains and their real weightings.

## Structure

- **phase1-operating-systems/** (28%) — 8 files: OS fundamentals & filesystems, Windows editions/installation, application management, Windows networking, Control Panel/Settings, admin tools & command line, macOS/Linux essentials, mobile OS & connectivity
- **phase2-security/** (28%) — 6 files: physical/logical security & social engineering, authentication/wireless protocols, malware & the official removal process, Windows security settings, SOHO/browser security, mobile security & data destruction
- **phase3-software-troubleshooting/** (23%) — 4 files: the CompTIA troubleshooting methodology, Windows OS problems, PC security symptoms, mobile OS/app troubleshooting
- **phase4-operational-procedures/** (21%) — 7 files: documentation & ticketing, change management, safety & environmental procedures, backup & recovery, professionalism/communication/privacy, scripting & remote access, cloud/virtualization basics
- **phase5-practice-exam/** — 60-question full practice exam weighted to match real exam domain percentages, plus a full answer key with explanations

## How to use it

1. Work through Phases 1–4 in order — each file has a "why this matters" framing, comparison tables, explicit exam-trap callouts, and a self-check with hidden answers.
2. Take the Phase 5 practice exam in one sitting under timed conditions (~75–90 min) before checking answers.
3. Use the scoring guide in `answer-key.md` to identify weak domains, revisit those specific files, and retake the exam.

Total: 25 study files + 1 full practice exam + answer key, covering 100% of the 220-1202 exam blueprint.
