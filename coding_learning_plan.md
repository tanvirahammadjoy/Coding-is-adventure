# Learning to Code: Web + AI Path (Beginner)

Goal: go from zero to building web apps, with a path into AI. Plan assumes ~1 hour/day.

## Month 1: Programming Foundations (Python)

**Weeks 1-2**

- Resource: freeCodeCamp "Scientific Computing with Python" or _Python Crash Course_ (book)
- Topics: variables, data types, loops, conditionals, functions, lists/dicts
- Project: a command-line calculator or a text-based quiz game

**Weeks 3-4**

- Topics: file handling, error handling, basic OOP (classes/objects), working with APIs (requests library)
- Project: a script that pulls data from a free public API (weather, jokes, etc.) and displays it

## Month 2: Web Fundamentals

**Weeks 5-6**

- Resource: freeCodeCamp "Responsive Web Design"
- Topics: HTML structure, CSS layout (flexbox/grid), responsive design
- Project: a personal portfolio page (static)

**Weeks 7-8**

- Resource: freeCodeCamp "JavaScript Algorithms and Data Structures"
- Topics: JS syntax, DOM manipulation, events, fetch API
- Project: add interactivity to your portfolio (dark mode toggle, contact form validation)

## Month 3: Real Web Apps

**Weeks 9-10**

- Backend: Flask (Python) — routes, templates, forms, connecting to a database (SQLite)
- Project: a simple to-do list app with a backend

**Weeks 11-12**

- Frontend: React basics — components, props, state, hooks
- Project: rebuild the to-do app frontend in React, calling your Flask API

By end of month 3: you can build and deploy a full-stack app (deploy free on Render/Vercel/Railway).

## Month 4+: Branch into AI

**Weeks 13-14**

- Topics: NumPy, Pandas — data manipulation basics
- Resource: Kaggle's free "Python" and "Pandas" micro-courses

**Weeks 15-18**

- Resource: Andrew Ng's Machine Learning Specialization (Coursera, audit free) or fast.ai's "Practical Deep Learning"
- Project: train a simple model on a Kaggle dataset (e.g., housing prices, image classifier)

**Ongoing**

- Once comfortable, explore using LLM APIs (OpenAI/Anthropic) to build AI-powered features into your web apps — this connects both tracks directly.

## Daily Practice

- exercism.org or Codewars: 15-20 min of small drills to reinforce syntax
- Read/debug real code, not just tutorials — tutorials teach recognition, projects teach recall

## Key Principle

Build something every week, even small and ugly. Tutorials alone don't produce the skill — struggling through your own broken code does.
